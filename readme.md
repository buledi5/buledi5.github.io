
# Neon Cast

Neon Cast is a GTA-style open-world game built with HTML, CSS, and JavaScript.

## Features
- Open-world exploration
- Character movement and controls
- Mobile and desktop browser support
- Lightweight web-based gameplay

## Requirements
- Modern web browser
- Android phone or PC
- Python 3 for o local hosting

## Run in Termux

1. Install Python:

   pkg install python

2. Open your game folder:

   cd Neon-Cast

3. Start the local server:

   python -m http.server 8080

4. Open this address in your browser:

   http://127.0.0.1:8080

## Project Files

- index.html - Main game
- style.css - Game styling (if used)
- script.js - Game logic (if used)
- requirements.txt - Optional server requirements
